# طراحی مدار کیت کنترل ۴ رله با پیامک (SIM800L + ATmega32)

> نسخه ۱.۰ — طراحی مرجع بر اساس مشخصات محصول:
> ۴ خروجی رله، تغذیه ۱۲V DC، ATmega32، SIM800L، LCD گرافیکی ۱۲۸×۶۴ با تاچ مقاومتی،
> کنتاکت رله تا ۷A / ۲۴۰VAC.

---

## ۱. بلوک دیاگرام

```
   12V DC IN
      │
   [FUSE 3A] [P-MOSFET محافظ قطبیت معکوس] [TVS]
      │
      ├──────────────► کویل ۴ رله 12V (SRD-12VDC)
      │
      ├──► [Buck #1  MP1584 → 5.0V / 3A] ──► ATmega32, GLCD, ULN2003, بوق
      │
      └──► [Buck #2  MP1584 → 4.0V / 2A] ──► SIM800L  (+2200µF کم‌ESR)
                                                    │
                                              [SIM socket]

  ATmega32 ──UART(9600)── [Level shifter 5V↔2.8V] ── SIM800L
           ──BUS── GLCD KS0108 + تاچ ۴سیمه
           ──PORTD── ULN2003 ── ۴ رله ── ترمینال پیچی
```

## ۲. نقشه پایه‌ها (Pin Map)

ATmega32A در پکیج DIP-40، کریستال ۱۶MHz.

| پین MCU | عملکرد | مقصد |
|---|---|---|
| PB0…PB7 | باس داده GLCD (D0…D7) | LCD 12864 (با مقاومت سری ۱۰۰Ω) |
| PC0 | CS1 | GLCD (نیمه چپ) |
| PC1 | CS2 | GLCD (نیمه راست) |
| PC2 | RS (D/I) | GLCD |
| PC3 | EN | GLCD |
| PC4 | RST | GLCD |
| PC5 | Backlight | ترانزیستور BC337 + LED پنل |
| PC6 | — | RESET (پین ۹، دست نزنید) |
| PC7 | NETLIGHT | ورودی وضعیت شبکه SIM800L |
| PA0 (ADC0) | تاچ X+ | پنل تاچ |
| PA1 (ADC1) | تاچ X− | پنل تاچ |
| PA2 (ADC2) | تاچ Y+ | پنل تاچ |
| PA3 (ADC3) | تاچ Y− | پنل تاچ |
| PA4 (ADC4) | اندازه‌گیری ولتاژ ورودی | تقسیم‌کننده ۱۰k/۲.۲k |
| PD0 (RXD) | دریافت از SIM800L | TXD ماژول (بعد از Level shifter) |
| PD1 (TXD) | ارسال به SIM800L | RXD ماژول (بعد از Level shifter) |
| PD2…PD5 | فرمان ۴ رله | ULN2003 (IN1…IN4) |
| PD6 | PWRKEY | بیس BC817 → PWRKEY ماژول |
| PD7 | Buzzer | بیس BC337 + بوق فعال ۵V |
| PB5/PB6/PB7 | ISP | هدر ۶ پین پروگرام |
| AVCC | تغذیه آنالوگ | ۵V + فریت + ۱۰۰nF |
| AREF | مرجع ADC | ۱۰۰nF به GND |

**نکته مهم:** GLCD پایه R/W ندارد (به GND وصل می‌شود) و درایور برای رسم از بافر سایه‌ای ۱KB در RAM استفاده می‌کند.

## ۳. منبع تغذیه — بخش حساس مدار

SIM800L در لحظه ارسال/ثبت روی شبکه تا **۲ آمپر** پالس می‌کشد. اگر تغذیه ضعیف باشد، ماژول ری‌استارت می‌شود یا شبکه را از دست می‌دهد. بنابراین:

| ریل | قطعه | مشخصه |
|---|---|---|
| 5V | ماژول MP1584EN | ۳A، خروجی ۵.۰V |
| 4.0V (SIM) | ماژول MP1584EN جداگانه | ۲A، خروجی ۴.۰V |
| ذخیره‌ساز SIM | خازن الکترولیتی کم‌ESR ۲۲۰۰µF + سرامیکی ۱۰۰nF + ۴۷۰µF | کنار پایه VBAT |
| محافظ | زنر ۵.۶V / ۱.۵W موازی با VBAT | جلوگیری از اسپایک |
| ورودی | فیوز ۳A + دیود/ماسفت معکوس + TVS (SMBJ15A) | حفاظت |

> ⚠️ هرگز SIM800L را مستقیم به ۵V یا به LDO ضعیف (مثل AMS1117) وصل نکنید — در پیک ۲A افت ولتاژ می‌کند و ماژول خاموش/روشن می‌شود.
> آداپتور پیشنهادی: **۱۲V / ۳A** (نه ۲A) تا هم رله‌ها و هم پیک GSM پوشش داده شود.

## ۴. اتصال SIM800L

| SIM800L | به |
|---|---|
| VBAT | ریل ۴.۰V (خازن‌دار) |
| GND | زمین مشترک (ستاره‌ای، نزدیک خازن) |
| VDD_EXT (2.8V) | فقط اندازه‌گیری/پول‌آپ — بارگیری نکنید |
| TXD | → Level shifter → PD0 |
| RXD | ← Level shifter ← PD1 |
| PWRKEY | کلکتور BC817 (بیس با ۴.۷k از PD6)، پالس ۱.۲ ثانیه به GND |
| NETLIGHT | از طریق ۱۰k به PC7 (و LED وضعیت) |
| RST | ۱۰k به VDD_EXT (یا کنترل اختیاری) |
| SPK±/MIC± | اختیاری — برای قابلیت شنود تماس |
| ANT | آنتن سیمی/PCB — دور از MCU و کریستال |

**Level shifter:** ماژول ۲ کاناله BSS138 (5V↔3.3V) یا 74HCT125 با تغذیه ۵V.
اتصال مستقیم ۵V به RXD ماژول مجاز نیست.

**سوکت SIM:** میکرو-SIM، سیم‌های DATA/CLK با مقاومت ۲۲Ω سری و خازن ۲۲pF، تغذیه SIM_VDD با ۱۰۰nF. سیم‌ها کوتاه (<۳cm).

## ۵. رله‌ها و خروجی برق شهر

- ۴ رله **SRD-12VDC-SL-C** (کویل ۱۲V، کنتاکت ۱۰A/۲۵۰VAC)
- درایور **ULN2003A** (دیود فلای‌بک داخلی، COM به +۱۲V)
- پول‌داون ۱۰۰k روی هر ورودی ULN2003 → جلوگیری از کلیک رله در زمان ری‌ست
- ترمینال پیچی ۳ پین برای هر کانال: **NO / COM / NC**
- وریستور **14D471K (275VAC)** بین NO و COM برای بارهای سلفی (موتور، پمپ)
- مسیر PCB حداقل **۲mm** عرض برای ۷A و فاصله خزشی ≥۳mm بین برق شهر و بخش ۵V

> ⚠️ **هشدار ایمنی:** سمت ۲۲۰V را فقط افراد مجرب سیم‌کشی کنند. حتماً در جعبه عایق با فیوز ورودی و ارت نصب شود. حتی در حالت خاموش، کنتاکت‌ها ممکن است برق دارند.

---

## ۶. نمایشگر و تاچ

- GLCD **128×64 با کنترلر KS0108** (۲۰ پین) — پتانسیومتر ۱۰k برای V0 کنتراست
- بک‌لایت: ۴ LED سفید، جریان ۸۰mA، از طریق BC337 با PWM/روشن-خاموش
- تاچ **۴ سیمه مقاومتی** روی پنل، ۴ خط به PA0…PA3
  - اندازه‌گیری Y: X+ = 5V، X− = GND، خواندن Y+ (ADC2)
  - اندازه‌گیری X: Y+ = 5V، Y− = GND، خواندن X+ (ADC0)
  - مقاومت سری ۱k روی هر خط برای حفاظت ADC
  - کالیبراسیون در EEPROM ذخیره می‌شود (دکمه ذخیره در صفحه کالیبراسیون)

## ۸. فوز بیت‌های ATmega32

| فیوز | مقدار | معنی |
|---|---|---|
| LOW | `0xFF` | کریستال خارجی ۸–۱۶MHz، بدون تقسیم ۸ |
| HIGH | `0x89` | **JTAG خاموش**، SPIEN فعال، CKOPT برنامه‌شده، بوت‌لودر غیرفعال |

> JTAG باید خاموش شود چون PC2…PC5 برای کنترل GLCD استفاده شده‌اند.

## ۹. مراحل ساخت

1. PCB یا بردبرد: ابتدا بخش تغذیه را ببندید و **بدون ماژول** ولتاژها را اندازه بگیرید (۵.۰V و ۴.۰V).
2. ATmega32 را با ISP پروگرام کنید (فیوزها را اول ست کنید).
3. GLCD و تاچ را وصل و با برنامه تست، کنتراست و کالیبراسیون را تنظیم کنید.
4. SIM800L را با آنتن وصل کنید؛ باید بعد از ~۱۰ ثانیه NETLIGHT چشمک بزند (ثبت روی شبکه).
5. رله‌ها و ULN2003 را اضافه کنید؛ با بار مقاومتی (لامپ) تست کنید، نه موتور.
6. شماره مجاز و رمز پیش‌فرض (`0000`) را با پیامک تنظیم کنید.
7. در نهایت سیم کارت را داخل کیت بگذارید و با اپ اندروید تست بگیرید.
