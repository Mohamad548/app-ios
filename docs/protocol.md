# پروتکل پیامکی کیت (SMS Protocol)

رمز پیش‌فرض کارخانه: `0000` — در EEPROM ذخیره می‌شود.

**همه دستورها به بزرگی/کوچکی حروف حساس نیستند** (`r1en0000` = `R1EN0000`).
شماره‌ها و رمز باید با **ارقام لاتین** ارسال شوند و پیامک باید **English / Plain text** باشد (نه Unicode).

---

## ۱. جدول دستورها

| عملکرد | فرمت | مثال |
|---|---|---|
| روشن کردن رله ۱ | `R1EN` + رمز | `r1en0000` |
| روشن کردن رله ۲ | `R2EN` + رمز | `r2en0000` |
| روشن کردن رله ۳ | `R3EN` + رمز | `r3en0000` |
| روشن کردن رله ۴ | `R4EN` + رمز | `r4en0000` |
| خاموش کردن رله ۱ | `R1DS` + رمز | `r1ds0000` |
| خاموش کردن رله ۲ | `R2DS` + رمز | `r2ds0000` |
| خاموش کردن رله ۳ | `R3DS` + رمز | `r3ds0000` |
| خاموش کردن رله ۴ | `R4DS` + رمز | `r4ds0000` |
| ذخیره شماره مجاز | `TEL1` + رمز + شماره | `Tel1000009xxxxxxxxx` |
| حذف شماره مجاز | `TEL1` + رمز | `Tel10000` |
| شنود مکالمات (تماس برگشتی) | `MIC1` + رمز | `mic10000` |
| تغییر رمز | `PASS` + رمز قدیم + رمز جدید | `pass00001234` |
| (الحاقی) وضعیت رله‌ها | `STATUS` + رمز | `status0000` |

> توجه: در دستور `PASS` ابتدا **رمز قدیم** و سپس **رمز جدید** می‌آید؛ مثال `pass00001234` یعنی رمز از `0000` به `1234` تغییر می‌کند.

---

## ۲. پاسخ کیت

| وضعیت | پیامک برگشتی |
|---|---|
| رله روشن شد | `R1 ON OK` (وضعیت کامل: `R1=1 R2=0 R3=0 R4=0`) |
| رله خاموش شد | `R1 OFF OK` |
| رمز اشتباه | `PASS ERROR` |
| دستور نامفهوم | `UNKNOWN CMD` |
| شماره ذخیره شد | `TEL SAVED` |
| شماره حذف شد | `TEL CLEARED` |
| رمز عوض شد | `PASS CHANGED` |

پاسخ با همان شماره‌ای که فرمان داده ارسال می‌شود.

---

## ۳. تنظیمات امنیتی (اختیاری)

- اگر شماره مجاز ذخیره شده باشد، **فقط** همان شماره حق کنترل دارد (سایرین: `ACCESS DENIED`).
- اگر خالی باشد، هر شماره‌ای با رمز صحیح می‌تواند کنترل کند.
- حداکثر ۳ تلاش اشتباه پشت سر هم از یک شماره → ۵ دقیقه قفل (ضد حمله brute-force).
- شماره مجاز برای دستور `MIC1` (تماس برگشتی) هم استفاده می‌شود.

## ۴. جریان کار ماژول در فریمور

```
Power On
  ├─ PWRKEY پالس ۱.۲ ثانیه
  ├─ AT → ATE0 → AT+CMGF=1 → AT+CNMI=2,1,0,0,0 → AT+CPMS="SM","SM","SM"
  ├─ AT+CREG?  تا ثبت شبکه (تکرار هر ۲ ثانیه)
  └─ حلقه اصلی
        ├─ هر ۳ ثانیه: AT+CMGL="REC UNREAD"
        ├─ استخراج شماره فرستنده + متن
        ├─ parse → اجرا → پاسخ
        ├─ AT+CMGD=<index>  (حذف پیامک پردازش‌شده)
        ├─ به‌روزرسانی GLCD و رله‌ها
        └─ اسکن تاچ هر ۲۰ms
```

### نکات پیاده‌سازی

- **CMGL** به‌جای اتکا به `+CMTI` انتخاب شده تا اگر ماژول ری‌ست شد، پیامک‌های نخوانده از دست نروند.
- پیامک‌ها بعد از پردازش با `AT+CMGD` حذف می‌شوند تا حافظه SIM پر نشود.
- اگر سیم‌کارت PIN دارد، `AT+CPIN="xxxx"` لازم است (در تنظیمات فریمور قابل تعریف).
- در زمان ارسال پیامک، رله‌ها نباید قطع شوند (تغذیه مشترک) — خازن SIM این را تضمین می‌کند.
- اگر متن پیامک بیش از ۱۶۰ کاراکتر بود، پیامک چندبخشی می‌شود؛ فریمور فقط بخش اول را می‌خواند (کدها کوتاه‌اند).

---

## ۵. تبدیل به اپلیکیشن

اپ اندروید فقط این رشته‌ها را می‌سازد و به شماره سیم‌کارت کیت می‌فرستد:

| کلیک کاربر | پیامک ارسالی |
|---|---|
| فن ۱ روشن | `R1EN<رمز>` |
| فن ۱ خاموش | `R1DS<رمز>` |
| دکمه «همه خاموش» | چهار پیامک `R1DS…R4DS` (یا یک دستور گروهی در نسخه بعد) |
| تست اتصال | `R1EN<رمز>` + خواندن پاسخ |

> پیشنهاد توسعه بعدی: دستور گروهی `ALLEN` / `ALLDS` برای خاموش کردن همزمان ۴ رله با یک پیامک (کاهش هزینه SMS).
